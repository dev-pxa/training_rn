## 2. 登录

用户使用企业代码、用户名/工号和密码进行登录。

### 接口信息

| 项目 | 内容 |
|------|------|
| URL | `/login` |
| 方法 | `POST` |
| 是否需要认证 | 否 |
| Content-Type | `application/json` |

### 请求参数

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| companyCode | String | 是 | 企业代码 |
| username | String | 是 | 工号/手机号 |
| password | String | 是 | 密码 |

### 请求示例

```json
{
  "companyCode": "SMART-HOME-01",
  "username": "admin",
  "password": "123456"
}
```

### 响应示例

```json
{
  "token": "mock_token_1716789012345",
  "user": {
    "id": "user_001",
    "username": "admin",
    "name": "管理员",
    "avatar": null,
    "companyCode": "SMART-HOME-01",
    "companyName": "智家科技总部"
  }
}
```

### 响应字段说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| token | String | 是 | 认证令牌，后续请求需在 Header 中携带 |
| user | Object | 是 | 用户信息 |
| user.id | String | 是 | 用户 ID |
| user.username | String | 是 | 用户名/工号 |
| user.name | String | 是 | 用户姓名 |
| user.avatar | String/null | 否 | 用户头像 URL |
| user.companyCode | String | 是 | 企业代码 |
| user.companyName | String | 是 | 企业名称 |

### 错误响应

#### 400 Bad Request - 参数错误

```json
{
  "error": "Invalid parameters",
  "message": "请检查用户名和密码"
}
```

#### 401 Unauthorized - 认证失败

```json
{
  "error": "Unauthorized",
  "message": "用户名或密码错误"
}
```

## 数据模型

### Company（企业信息）

```typescript
interface Company {
  code: string;
  name: string;
}
```

### Agreement（协议内容）

```typescript
interface Agreement {
  serviceAgreement: {
    title: string;
    content: string;
  };
  privacyPolicy: {
    title: string;
    content: string;
  };
}
```

### LoginConfigResponse（登录页配置响应）

```typescript
interface LoginConfigResponse {
  companies: Company[];
  agreements: Agreement;
}
```

### LoginRequest（登录请求）

```typescript
interface LoginRequest {
  companyCode: string;
  username: string;
  password: string;
}
```

### LoginResponse（登录响应）

```typescript
interface LoginResponse {
  token: string;
  user: {
    id: string;
    username: string;
    name: string;
    avatar?: string;
    companyCode: string;
    companyName: string;
  };
}
```
